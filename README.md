# session-usage

A Claude Code plugin that adds a usage side pane: context window, 5-hour and weekly limits, where context goes, recent tool calls, turns, cost and burn rate.

- Opens automatically at session start (`autoOpen` option); `/usage-bar` reopens it
- Buttons: Refresh, Reset counts, Hide/Show tools, Hide/Show breakdown

Pair it with [session-link](https://github.com/Creeperprol/session-link) for linking sessions. Load it as a Claude Code mod from this folder.
